## What I Value

1. 기능을 구현하기 전에 사용자와 서비스가 실제로 해결해야 할 문제를 정의합니다.
2. 엔진 내부에 머무르지 않고 운영체제, 서버와 외부 도구의 상호작용까지 살펴봅니다.
3. 성능과 품질을 감으로 판단하지 않고 측정 결과와 재현 가능한 테스트로 검증합니다.
4. AI가 만든 결과를 그대로 채택하지 않고, 목표와 검증 기준을 구체화해 사람이 최종 판단합니다.
5. 다른 직군이 이해하고 활용할 수 있는 구조와 문서를 만드는 것을 중요하게 생각합니다.
